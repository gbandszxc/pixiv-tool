# 领域词库：文学 / 小说 / 诗歌

资源 ID：`reference:domain-literature`

适用于文学作品、小说章节、诗歌、散文、剧本等。本词库是译法候选与领域惯例，不是已查证事实；无法核实时在术语 `notes` 标注依据不足，不得声称“官方译名已查证”。

---

## 核心原则

文学翻译的目标是**在准确的基础上重现原文的美感、节奏和修辞**。
允许为保留节奏调整句式，但不得改变原意。
诗歌翻译优先保留意象，格律次之。

## 翻译处理原则

| 情况 | 处理方式 |
|------|---------|
| 文化典故（无对应） | 意译 + 译注说明出处 |
| 双关语 | 优先找对应双关；不能时意译主要义，译注说明另一义 |
| 方言/口音 | 用相对应的中文语感模拟，不逐字音译 |
| 诗歌押韵 | 保留可保留的韵脚；不强求与原文韵脚一致 |
| 古英语/文言风格 | 译成相应的文言或半文言，保持文体层次 |
| 意识流长句 | 保留长句结构，仅在理解断裂处加标点 |

## 日文小说日译中注意事项

仅当源语言为日语且目标语言为 `zh-CN` 或 `zh-TW` 时适用。日文小说里的假名残留会让中文读者直接看到未翻译痕迹。即便原文使用假名是为了制造语气、声音或身体感，译文也应把这种效果转化为中文表达。

| 情况 | 处理方式 |
|------|---------|
| 日语助词、语尾、敬体/简体残片 | 不保留原文；结合人物关系和语气转成中文句式、语气词或标点 |
| 平假名拟声/拟态词 | 按上下文译为中文声音、状态或动作描写，例如吸吮声、液体声、心跳一惊、黏滑感 |
| 片假名拟声/拟态词 | 不因片假名形式而保留；同样转为中文可读的声音或状态描写 |
| 片假名专有名词 | 冻结表或上下文已有官方英文名时使用；否则按通行罗马字转写或给出中文译名，不在最终中文稿中残留片假名 |
| 口癖和重复语气 | 保留角色声音，但用中文口癖、重复、停顿和句长体现，不复制假名 |

## 情感词处理

避免过度翻译（原文克制时译文也应克制）：

| 原文风格 | 译文对应 |
|---------|---------|
| 克制、留白 | 不补足情感词，保留空白 |
| 直白宣泄 | 对应强度的直白表达 |
| 讽刺疏离 | 保持语气距离，不“热化” |
| 诗意朦胧 | 不追求字字清晰，保留模糊感 |
