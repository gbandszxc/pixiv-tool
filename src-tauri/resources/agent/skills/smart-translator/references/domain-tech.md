# 领域词库：技术文档 / 软件开发

资源 ID：`reference:domain-tech`

适用于 API 文档、开发者指南、技术博客、README、架构说明等。本词库是译法候选与领域惯例，不是已查证事实；无法核实时在术语 `notes` 标注依据不足，不得声称“官方译名已查证”。

---

## 核心原则

技术文档翻译的首要目标是**准确无歧义**，其次才是流畅。
约定俗成的英文术语（如 API、token、pipeline）通常保留英文，不强行意译。
