## 日译中目标语纯净度

仅当源语言为日语且目标语言为 `zh-CN` 或 `zh-TW` 时适用。ACG、轻小说、台本、字幕和同人文本常把角色口癖、语尾、拟声拟态词和片假名专名密集写在对白里。翻译成中文时，最终稿的自然语言区域必须让中文读者顺读，不应残留未处理日文假名。

| 情况 | 处理方式 |
|------|---------|
| 日语助词、语尾、敬体/简体残片 | 不保留原文；结合角色关系、情绪和口癖转成中文语气、句式、停顿或标点 |
| 口癖 / 萌系语尾 | 保留角色声音，但用中文口癖或句式体现，不直接留下 `です`、`ます`、`なの`、`にゃ` 等残片，除非用户明确要求保留 |
| 平假名拟声/拟态词 | 按上下文译成中文声音、动作或状态描写，例如心跳、吸气、液体声、脚步声、黏滑感、抱紧动作 |
| 片假名拟声/拟态词 | 不因片假名形式而保留；同样转成中文可读的声音或状态描写 |
| 片假名角色名 / 地名 / 技能名 / 道具名 | 冻结表或上下文已有官方英文名时使用；否则按通行罗马字转写或使用已确定中文译名，不在最终中文稿中残留片假名 |
| 招式名、系统词、UI 文本 | 按作品语境统一锁定译法；若保留英文更符合游戏/设定语感，应在 Pass 1 术语表中说明 |

质检时，只要中文最终稿自然语言区域出现未处理的 `です`、`ます`、`の`、`へ`、`と`、`じゅるっ`、`ドキッ`、`ぎゅっ` 等假名残留，或片假名专名没有转成英文名/罗马字/中文锁定译名，就应标记为 `needs_fix`。代码、URL、文件路径、用户明确要求保留的原文引用除外。
