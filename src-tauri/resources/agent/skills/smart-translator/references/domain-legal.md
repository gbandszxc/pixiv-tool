# 领域词库：法律 / 合同 / 监管

资源 ID：`reference:domain-legal`

适用于合同文本、法律条款、监管文件、法院判决、隐私政策等。本词库是译法候选与领域惯例，不是已查证事实；无法核实时在术语 `notes` 标注依据不足，不得声称“官方译名已查证”。

---

## 核心原则

法律翻译首要目标是**精确无歧义**。
法律术语有时需要保留原文并附译文，尤其是合同中的定义条款。
"shall" 译「应」，"may" 译「可」，"must" 译「必须」——三者不可混用。

## 句式处理规范

| 英文模式 | 中文处理 |
|---------|---------|
| shall not | 不得 |
| shall | 应当 / 应 |
| may | 可以 / 可 |
| must | 必须 |
| subject to | 受……约束 / 在……前提下 |
| notwithstanding | 尽管如此 / 不管…… |
| to the extent that | 在……范围内 |
| as the case may be | 视情况而定 |
