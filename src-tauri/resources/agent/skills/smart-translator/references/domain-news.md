# 领域词库：新闻 / 时事 / 政治

资源 ID：`reference:domain-news`

适用于新闻报道、时评、政策文件、外交声明等。本词库是译法候选与领域惯例，不是已查证事实；机构名、职衔等无法核实时，在术语 `notes` 标注依据不足，不得声称“官方译名已查证”。

---

## 核心原则

新闻翻译首要原则是**客观准确**，译者立场不应渗入。
机构名、职衔以冻结表已有的官方中文译名为准；没有时使用音译加括号注释，并记录依据。

## 新闻写作惯用句式

| 英文模式 | 中文处理 |
|---------|---------|
| According to sources familiar with... | 知情人士透露…… |
| Officials said on condition of anonymity | 官员匿名表示 |
| The White House did not immediately respond | 白宫未立即回应 |
| In a statement, [机构] said... | [机构]在声明中表示…… |
| The move comes amid... | 此举发生在……背景下 |

## 注意事项

- 国家/地区领导人职衔：使用冻结表已有的惯用译法；没有时记录依据，不自行发明。
- 争议地区表述：保持原文立场，不主动加注，如需注释说明系原文用法。
- 数字单位：billion 译为十亿，trillion 译为万亿；不把十亿误写为百亿。
