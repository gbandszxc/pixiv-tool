# 领域词库：学术 / 论文 / 科学

资源 ID：`reference:domain-academic`

适用于学术论文、研究报告、科普文章、技术综述等。本词库是译法候选与领域惯例，不是已查证事实；学科内权威译名无法核实时，在术语 `notes` 标注依据不足，不得声称“官方译名已查证”。

---

## 核心原则

学术翻译首要目标是**术语精确、逻辑清晰**。
同一概念在全文中必须使用同一译法，不得混用近义词。
学科内已有权威译名的术语，严格沿用，不自行创译。

## 常见学术表达句式

| 英文模式 | 中文处理 |
|---------|---------|
| We propose / suggest | 本文提出 / 我们提出 |
| Our findings indicate | 研究结果表明 |
| This is consistent with | 这与……一致 |
| In contrast to | 与……相比 / 与之相对 |
| It remains unclear whether | ……仍不明确 |
| To the best of our knowledge | 据我们所知 |
| Further research is needed | 仍需进一步研究 |

## 翻译注意事项

- **数字与单位**：保留原文单位制，不换算，除非读者群有明确需求
- **缩写**：首次出现展开全称，之后直接用缩写
- **被动语态**：学术英文大量使用被动，中文可转为主动，但不改变施事逻辑
- **过度限定语**：英文中 "which", "that" 嵌套从句，中文拆成短句更清晰
