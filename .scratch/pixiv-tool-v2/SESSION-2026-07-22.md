### 重要踩坑记录（给下任 agent）

1. **`build/pixiv-tool/pixiv-tool.exe` 是中间产物不能跑**——只有 `dist/pixiv-tool/pixiv-tool.exe` 可用。前者缺 `_internal/python313.dll`，双击报 `LoadLibrary` 失败
2. **PyInstaller 6+ 拒绝 makespec 选项与 .spec 共用**——spec 已声明 onedir 就不能再传 `--onedir`
3. **`console=False` 时 `sys.stdout` 是 None**——uvicorn/pywebview 等库调 `isatty()` 必崩，必须重定向到文件
4. **spec 的 `datas` 第二个参数是 bundle 内目标路径**——必须和代码里 `_MEIPASS` 拼接路径一致，否则 frozen SPA 404
5. **frozen 模式下 `__file__` 指向临时解压目录**——不能用 `__file__` 锚定数据/静态资源，要用 `sys._MEIPASS`（bundled 数据）或 `sys.executable.parent`（用户数据）

## 8. 重要约定 / 踩坑记录（给下任 agent，补充 07-19 §5）

### 8.1 PyInstaller + console=False 的 5 个坑

1. `sys.stdout` / `sys.stderr` 是 `None`，任何调 `.isatty()` 的库都崩 → `_redirect_stdio_if_needed()` 重定向到文件
2. `__file__` 指向 `_internal/backend/main.py`（临时解压目录），锚定数据要用 `sys._MEIPASS`（bundled 资源）或 `sys.executable.parent`（用户数据）
3. frozen exe 单入口 bootloader 不认 `-m`，子进程要用 `sys.executable --login-window` 自我分发
4. `inspect.getsource` 拿不到源码（PYZ 归档），frozen 时要跳过
5. spec 的 `datas` 第二参数是 bundle 内目标路径，必须和代码里 `_MEIPASS` 拼接路径一致

### 8.2 PyInstaller 命令行约束

- `.spec` 文件已声明 onedir（通过 COLLECT）就不能再传 `--onedir` / `--onefile`（PyInstaller 6+ 显式拒绝 makespec 选项与 .spec 共用）
- `--noconfirm` 仍合法（覆盖 dist 不问 y/N）

### 8.3 dev.ps1 的隐藏约束

- PowerShell 5.1（Windows 自带）不支持 `??` 空合并、`$PID` 是只读变量、函数返回单元素数组会退化为标量（要用 `@(func)` 包装）
- `taskkill /F /T` 强杀进程树，不留孤儿
- Windows TCP 内核级 TIME_WAIT/CLOSE_WAIT 僵尸 socket，用户态清不掉，靠等或换端口
