- 限速 2 并发 + 0.4s 在真实网络下是否够保守

- vue-tsc 编译在 build 模式下的差异
- 前端 `backend/static/` 挂载在 prod 模式下是否正确 serve SPA

把 F2.3/F2.4 + V2 待做项（EPUB、macOS keychain、安装器等）登记到 `.scratch/pixiv-tool-v2/issues/`。**不推荐现在做**——A/B 优先，因为它们会暴露更多需要 V2 修的问题。

## 5. 重要约定 / 踩坑记录（给下任 agent）

### 5.1 pywebview 的 5 个隐藏约束（ADR 0005）

实施 login_window / 主窗时必须遵守，否则必踩坑：

1. `window.get_cookies()` 返回 `list[SimpleCookie]`，要遍历 `.items()` 取 `(name, Morsel)`
2. `SimpleCookie.Morsel` **继承自 dict**，判断 dict 路径要 `not isinstance(morsel, Morsel)`
3. 读 value 要 `getattr(morsel, "value")`，**不能**用 `morsel.get("value")`（永远空）
4. `evaluate_js` 同步模式**不 await Promise**，async 函数返回 None；必须用 callback 模式
5. JS 写成 `new Promise(...)` 而非 `async () => {...}`，pywebview 识别更可靠

### 5.2 Pixiv 接口的真实约束（spike 实测）

- 登录态检查：`/ajax/user/self?lang=zh` 返回 `userData.{id, pixivId, name}`（**不是** `/ajax/user/self/status`，那个 404）
- csrf token 路径：`__NEXT_DATA__.props.pageProps.dehydratedState.queries[*].meta.apiClient.token`
  - 不是 `pageProps.token`（空）
  - 不是 `state.data.token`（react-query 刷新后消失）
- 未实测的接口（系列/用户全集）路径是推测的，A 步实测时要重点验证

### 5.3 调度 agent 的失败模式

这次子 agent 犯过的错（下次避免）：
- **空验收**：标 ticket done 但不跑 build / 不实测端点
- **不复用成果**：ADR 0005 警告过的 bug 在 login_window 复发
- **测试形式主义**：用"括号配对"凑测试数

DISPATCH.md 已加入 4 项防错措施（提供正确代码模板、强制贴验证输出、明示边界、禁止改测试讨好），下次派子 agent 时严格执行。

- **dev 端口**：前端 9961、后端 9962（固定）
