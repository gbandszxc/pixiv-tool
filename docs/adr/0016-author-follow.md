# ADR 0016 — 作者关注与浏览写操作边界

日期：2026-10-03 · 状态：已接受

## 背景

作者详情页只有资料、作品和外链，没有关注入口。用户明确要求补齐关注操作。ADR 0012 最初规定浏览只读，后续已接入作品收藏；本次明确扩展这一边界，保留历史决策原文。

## 决策

- 浏览模式允许作品收藏与作者关注/取消关注，不扩展点赞、评论发布或批量关注。
- 作者页默认公开关注；资料端点的 `isFollowed` 是状态来源，缺失为未知。本人资料不提供关注自己，未知状态禁用并引导刷新。
- 增加 `browse_user_follow(id, followed)` IPC，由 Rust 复用现有凭据、CSRF、客户端限速与登录守卫发送旧式表单；端点和成功信标记录在 PIXIV-API §4.10。凭据不进入前端或数据库。
- 只有服务端成功响应才更新按钮；失败保留状态，提交禁用防重，账号切换后忽略旧请求回显。作品列表、分页和缓存不因关注而重建。
- 离线验收覆盖成功、失败、防重、自身和账号切换。真实写往返仍需 ignore + PIXIV_LIVE_WRITE=1，动态取未关注的非本人作者，私密关注后先尝试取消恢复再断言。

## 影响

无新增依赖、数据库表或设置键。新增一个 IPC 和可选资料字段。主站若要求额外风控验证，原始失败保留并提示，不模拟成功；可通过已有网页入口处理。
