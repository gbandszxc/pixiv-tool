# ADR 0015 — 核心导航与非模态下载工作区

日期：2026-10-03 · 状态：已接受

## 背景

浏览入口逐步增加，频道、探索方式、个人内容与工具在侧栏平铺。下载返填通过路由离开当前作品，削弱浏览与下载的连续性；任务事件监听局限于任务页。

## 决策

- 将 ADR 0012 的平铺浏览入口组织改为发现 / 关注 / 我的 / 下载四个核心入口；保留现有浏览路由与接口，详情继承实际来路分组，直达默认发现。
- 下载表单从独立路由改为应用级非模态右栏 / 底栏，公共 DownloadTarget 返填接口保留、动作改为就地打开。旧表单路径兼容到任务页并打开对应表单。新建下载不改变当前路由历史，草稿只在会话中保存、账号变化时清空。
- 增加独立占位的 32px 常驻任务状态栏；点击进度进入完整任务页，真实返回恢复浏览缓存。任务事件与 2 秒兜底轮询由应用生命周期统一管理，状态栏与任务页共享 store。
- 搜索从侧栏迁为固定文字胶囊及 Ctrl+K / Command+K；阅读器采用顶栏入口，全屏隐藏全局控件。以图识图入口放在搜索页。
- 真实路由历史优先；无历史以 replace 回所属核心入口，核心入口回推荐首页。继续复用 20 页 LRU、账号失效、首页快照和手动刷新策略，面板开关不重挂浏览页。

## 后果

侧栏只表达使用场景，浏览与下载同等可见。宽度变化可能引起卡片重排，因此布局切换保持可见卡片锚点。非模态表单需要独立滚动、焦点恢复、来源覆盖确认与提交保护。视觉规格同步维护于 DESIGN / 结构化伴随文件；不增加外部依赖、不改 Rust IPC、数据库或 Pixiv 契约。ADR 0012 的接口代理、分页和图片协议决策仍有效。
