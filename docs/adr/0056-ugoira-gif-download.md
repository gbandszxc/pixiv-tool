# ADR 0056 · ugoira 下载导出为循环 GIF

**状态**：已接受 · **日期**：2026-11-25 · **关联 SPEC**：§4.4、§7、§8.2

## 背景

ugoira 的 ZIP 包含独立帧图，播放时长由 Pixiv 的元数据另行提供。用户需要能直接打开播放的下载文件。本决策更新 ADR 0039 的下载产物格式，复用 ADR 0007 的原始尺寸下载入口。

## 决策

- 单作品、用户全集和图片右键保存共用 GIF 导出。取 `originalSrc` 或 `zip_urls.original`，按 `frames` 的顺序读取 ZIP 中的 JPEG / PNG 帧，保留帧尺寸。按 GIF 的 10ms 单位四舍五入帧时长，写入无限循环标记。
- 转码在阻塞线程中逐帧执行。使用 `image` 解码、`gif` 编码、`tempfile` 在目标目录提交完整文件。落盘后才更新下载历史，默认文件名为 `<title>_<artworkId>_ugoira.gif`，继续应用已有插画命名模板。
- 现存 GIF 可直接复用。旧 ZIP 和旧历史记录在重新下载前仍可访问，成功生成 GIF 后以新路径更新该作品历史，原 ZIP 文件保留。详情页内的逐帧播放继续使用 ADR 0039 的独立帧缓存。

## 后果

GIF 可用常见图片查看器直接播放。GIF 帧颜色需量化至索引调色板，原始尺寸动图会增加转码耗时，文件大小随帧数和图像内容变化。
