# ADR 0040：更新下载与安装分离，系统交接成功后退出

- 日期：2026-10-28
- 状态：已接受
- 取代：ADR 0016 中“下载完成立即打开安装包、应用不自动退出”的交互决策；资产来源、校验与包匹配规则保持有效。

## 背景

macOS 打开 DMG 后仍需手动退出当前应用才能顺利覆盖；Windows 安装器也可能等待当前程序退出。下载完成立即退出会打断用户正在进行的阅读或后台任务，因此退出时机应由用户明确选择。

## 决策

下载与安装拆为独立 IPC。`download_app_update` 只下载、校验并记录完整包路径，返回 `{path, package_type}`；进度 Channel 仅发送 `downloading`。新增 `install_app_update`，只读取后端记录的已完成包，不接收前端路径。下载时记录实际大小与 SHA256；安装前重新核对普通文件、大小与摘要，系统打开失败则返回错误、保持应用运行；系统接受打开请求后由后端 `app.exit(0)`，跳过普通退出确认。不用固定延迟判断安装器是否启动，不宣称安装窗口已经出现或安装已经完成。

前端在 ready 状态提供“退出并安装更新 / 稍后安装”，并提供目录定位和重新下载。下载中可收起弹窗继续使用应用，Esc 同效；显式取消才取消下载。后台完成或失败走现有通知；再次检查更新可恢复同一会话内的状态与已完成包，不重复下载。更高版本重新进入下载流程。

点击安装时先读取最新翻译任务列表（失败视为状态未知）；如有未完成下载、未终结翻译 Job（含暂停、等待确认、需要处理），或下载任务状态同步失败，在同一弹窗显示退出中断影响并要求确认一次；确认后不再弹普通退出确认。打开安装包期间锁定关闭和重复安装操作。启动失败回 ready，保留包、错误和恢复入口。

Windows 继续交给 MSI/NSIS 安装向导；macOS 打开 DMG 并退出后，仍需用户拖入 Applications 覆盖；Linux 保留原包类型安装/替换说明。安装后由用户重启应用，不增加静默安装、自动替换或自动重启。

## 影响与验证

新增一个 IPC，命令总数从 81 增至 82。修改下载返回体与进度 phase，前后端同批更新。不改 CI 产物格式、签名和更新源。完成包仍由系统临时目录生命周期管理，重新下载可恢复临时文件被清理的情形。

离线 Rust 测试覆盖下载完整性与进度；真实 Vue 组件搭配官方 IPC mock 覆盖取消、后台下载、稍后安装恢复、迟到进度、平台说明、任务确认、打开失败重试和安装动作防重。离线验证不启动真实安装包或退出当前应用；Windows/macOS 的安装器交接仍需对应平台实机验收。
