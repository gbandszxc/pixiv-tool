# ADR 0016：应用内更新下载与安装引导

- 日期：2026-10-03
- 状态：已接受

## 背景

检查更新目前只打开 GitHub Release 页，用户须自行选择平台、架构、安装包类型。
需要在现有 Tauri 进程内完成下载并交接系统安装器，下载过程中可见进度、速度且可取消。

## 决策

保留已有稳定版检查与用户确认。增加 download_app_update/cancel_app_update/open_update_directory
IPC 契约及进度 Channel；不引入服务器或无人值守安装。下载从固定仓库 Release 资产元数据选取，
按编译架构、Tauri bundle_type 标记及 CI 命名精确匹配，未知格式不猜测、不跨类型回退。
macOS .app 交付形式对应 DMG；读取可执行文件 Mach-O 魔数保留 universal 类型。

更新包落在系统临时目录的版本/随机子目录，以 .part 写入；大小与可用 SHA256 校验通过再 rename。
客户端无登录凭据，与 Pixiv 请求隔离。取消/失败清理该次下载，完成包保留至系统清理临时目录。

下载完成请求系统打开；Linux/macOS 检查打开命令的退出状态，不能把派生进程成功等同安装器已打开。
无法打开则文件管理器定位或打开父目录。即使都失败，也保留完整路径并进入安装引导，不将下载成功改判为失败。
安装由操作系统与用户完成，不自动退出应用，不直接改程序文件，不把 GitHub 摘要当作签名或信任根。

## 影响

增加 GitHub REST 元数据依赖（匿名限额/网络失败自动回退发布页 `expanded_assets/<tag>` 网页片段：
同 github.com 域、不受 API 匿名限额影响，片段含资产名与 SHA256 摘要但无精确字节大小，
下载期以响应 Content-Length 对账；两通道均失败才报错），wreq 开启 stream feature、
使用 sha2 流式哈希；沿用版本锁与系统代理/直连策略。debug/未知便携形式无法自动判断安装方式，
给出发布页兜底；未来新增发布格式须同步匹配规则、PACKAGING 与测试。完成包由系统临时目录生命周期管理，
避免清理可能正在使用的安装包。
