# ADR 0027：缓存与日志维护及模型错误诊断

- 状态：已采纳
- 日期：2026-10-04
- 关联：ADR 0017、0025

## 背景

设置缺少缓存统计/清理、路径复制和日志查看入口；模型服务错误只有界面概括，难以定位原始错误。ADR 0017 的服务正文不回显原则仍适用于界面，日志允许记录脱敏后的错误诊断字段。

## 决策

新增维护 IPC `maintenance_info`、`read_logs`、`clear_cache(kind)`；路径只由 AppPaths 派生，kind 只允许 translation/images。统计 translations、cache/img 的文件字节数和数量及 logs 下所有普通 .log 文件的总大小。清缓存不删除数据库、设置、登录态或下载作品；拒绝链接目录；翻译进行中通过共享互斥锁拒绝清理译文。成功清理译文后同步清除阅读器的内存回显。

设置维护组显示缓存分类/总大小、日志总大小、对应路径复制按钮及确认后清理入口。最近日志每 2 秒轮询，大小每 10 秒统计；仅维护组挂载且窗口可见时读盘。读取 app.log 最后 64KiB/最多 200 行，错误保留旧快照并允许重试。clear_logs 原契约扩展为截断全部普通 .log 文件，保留活动 logger 句柄，后续写入继续。

日志查看器在末尾时跟随新行，手动向上阅读时保留位置。离线验收使用 `node frontend/tests/production-settings.mjs maintenance`（生产构建 + 打包 CSP + 浏览器 IPC mock），Rust 临时目录测试覆盖统计、边界、尾部读取与清理后的活动句柄继续写入；真实桌面只读核对大小/路径、复制到系统剪贴板及服务错误入日志，不清理用户现有数据。

翻译 HTTP 错误响应最多读取 64KiB；仅提取错误 code/type/message/param/request_id，SSE 错误同样处理。日志保留脱敏后的原始错误说明和流失败信号；已知 Key、凭据模式、URL 脱敏，控制字符压平、字符串限 4096 字。非 JSON 服务正文只记格式/大小，模型 JSON 解析只记类别、行列和长度；不记录请求、小说原文、模型生成正文或完整响应。超时/连接错误记录成因。

## 后果

无需额外后端、HTTP 端口或剪贴板插件。图片在途请求可能在清理后重新写入缓存，这是正常的按需恢复；译文缓存与翻译任务互斥。清理不可恢复，界面确认明确译文与设定集需重新生成的后果。日志统计覆盖遗留轮转文件；现有日志插件默认 KeepOne，8MiB 上限不变。
