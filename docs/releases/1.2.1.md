本次版本带来完整的小说翻译能力与浏览社区功能：小说阅读器支持逐段两轮翻译与跨页共享设定集；浏览模式支持发表评论、回复与官方表情；新版本可直接在应用内下载安装；设置新增「维护」页统一管理缓存与日志；图片缓存改为可配置上限并引入分区淘汰。

## 新增

- 小说翻译：小说阅读器可对当前页逐段调用模型翻译，两轮精翻与跨页共享设定集保持译名一致；翻译状态与选项收进阅读器底栏弹层，进度与成败一目了然。
- 翻译服务设置：支持 Chat Completions / Responses / Anthropic Messages 三种接口协议，可一键检测服务可用、获取模型列表；目标语言默认跟随界面语言、也可手动指定；单请求超时可配置（默认 10 分钟），与原文语言一致时快速返回不再重复翻译。
- 评论互动：浏览模式可发表评论与回复，支持官方文本表情与贴图。
- 应用内更新：检测到新版本后可直接在应用内下载并引导安装，实时显示下载进度。
- 维护页：设置新增「维护」，可查看并清理译文缓存、图片缓存与运行日志，复制目录路径、查看最近日志；模型调用失败时可在应用内查看脱敏后的错误诊断。
- 图片缓存上限可设置：256 MiB ~ 2 GiB 预设档与自定义输入（默认 512 MiB）；缓存按小图 / 大图 / 原图三档配额淘汰，看原图不再挤占缩略图缓存。

## 优化

- 设置与表单的冗长说明统一收进问号帮助提示，按需展开；维护页路径不再整段回显，改为小复制图标、点击即复制。
- 翻译生成请求改用流式传输，长请求不再被链路按空闲切断。

## 修复

- 切换账号：修复切换后「我的收藏 / 收藏标签 / 追更」仍显示上一个账号的数据、需退出程序重开才恢复的问题；登录、退出登录后同类残留一并修复，关注 / 收藏 / 评论等写操作在身份变更后不再沿用旧会话令牌导致首次操作失败。
- 浏览：作者页收藏 tab 误显示查看者自己的收藏，现正确展示该作者的公开收藏。
- 账号：退出登录在自动回退到剩余账号失败时不再误报「退出登录失败」（实际已登出），凭据已失效的账号会自动移出切换列表。
- 头像：侧栏头像偶发加载失败后不再持续显示首字母，现会自动重试恢复（并禁用本地缓存的失败结果）。
- 应用内更新：GitHub API 触发匿名限流时自动改用发布页资产清单，修复更新下载报「无法读取该版本的发布包」的问题。
- 凭据传输与资源生命周期安全修复；构建依赖升级至安全版本（Vite 6.4.3+ / Rust 1.88）。
- 翻译：设定集改写冲突时保留既有译名、不再中断整页；识别流末尾的审核错误并校验完成信号；连接失败时报出成因类别（DNS / 代理 / TLS / 拒绝 / 重置）；opencode 系网关补会话标识头。
- 浏览：系列分集页翻页器重新贴回底栏（含内容不足一屏的情形）；修复阅读背景按钮隐身与纸色模式下译文同色的问题。
