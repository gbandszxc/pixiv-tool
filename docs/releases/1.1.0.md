本次更新主要扩充了只读浏览模式，并统一了分页与图片查看体验。

## 新增

- **追更列表页**：聚合漫画与小说的订阅系列，分类型 tab + 系列行卡，布局对齐官方分区。
- **系列分集页**：支持插画 / 漫画两种系列类型，宫格与列表两种浏览模式，页码式翻页。
- **图片全屏查看浮层**：悬浮操作控件、双图（跨页）阅读模式、纵向渐进加载，缩略图三档尺寸（网格 / 详情 / 全屏）分别生效。
- **R-18 全局开关**：设置项控制展示，频道页提供快捷筛选。
- **公共分页组件**：历史 / 任务 / 排行榜 / 系列 / 阅读器统一分页交互，含总数回显、每页容量下拉、页码窗口与快捷跳页。
- 频道页新增 **# 标签推荐** 板块。
- 账号菜单增加版本回显与 GitHub 主页入口；退出登录前增加确认弹窗。

## 优化

- 图片代理通道放宽并发，同 URL 在途请求合并，图片响应使用长缓存。
- 减少图片缓冲复制，优化任务刷新与资源回收。
- 侧栏扁平化；设置改为模态弹窗，全局弹窗样式统一。

## 修复

- 作者已关闭评论区的作品不再显示 HTTP 400 错误，改为明确提示。
- 双图模式从右往左翻页时，翻页方向与阅读方向保持一致。
- 修复实机联调中暴露的多处 pixiv 接口解析缺陷。
