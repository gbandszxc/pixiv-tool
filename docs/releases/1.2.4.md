本次版本以翻译稳定性为主：修复 Anthropic 与 Responses 协议下思考不生效、长页因输出上限不足被截断的问题，输出上限改为按输入长度自动分档并默认开启思考；同时修正小说详情页的阅读时长单位，并新增发布时间展示。

## 修复

- 翻译思考不生效：思考参数此前只按 Chat Completions 的写法下发，Anthropic 会静默忽略 `reasoning_effort`、Responses 会拒绝顶层该字段，导致这两个协议直接开始输出译文、浮窗没有思考过程。现按协议归一化：Responses 转入嵌套的 `reasoning.effort` 并补 `summary`，Anthropic 转成 `thinking` 预算；开启思考时自动满足 Anthropic 的采样约束（`temperature` 为 1、`top_p` 不低于 0.95）。
- 长页翻译截断：此前 Chat Completions 不发送输出上限、Anthropic 固定 8192 / 16384，而开启思考后推理与译文共享同一份输出预算，长页常在思考阶段就耗尽额度，报「模型未完整输出」或 JSON 解析失败。现按本次输入长度分三档（≤6k 字符 16,384 / 6k~24k 65,536 / >24k 262,144），三种协议一致；高级 JSON 显式给出的上限仍然优先。
- 截断提示更明确：因输出上限截断时单独提示实际生效的上限值并给出可执行动作，与「被服务拒绝」等其它未完成情况区分；Chat Completions 协议下同样能取到该数值。
- 小说阅读时长单位：接口返回的是秒，此前按分钟直接展示会把 1976 秒显示成「约 1976 分钟」，现换算为分钟（不足 1 分钟按 1 分钟）。

## 优化

- 默认开启思考：高级 JSON 未给出任何思考字段时按中等强度开启，长文本译文的专名与语气一致性更好；想省 token 可在高级 JSON 写 `{"reasoning_effort":"none"}` 关闭。
- 高级 JSON 语义收束：用户填写的 JSON 与后台装配的请求参数是逐字段合并——没有的字段新增、同名字段覆盖后台默认值，而不是整块替换请求体；`model` / `messages` / `stream` / `store` / 系统提示等由应用控制的字段不可覆盖。设置页提示同步更新。

## 新增

- 小说详情发布时间：元信息行末尾展示作品发布时间，固定按 JST 显示，与 pixiv 网页端一致（不换算到本地时区，避免跨时区差一天）。
