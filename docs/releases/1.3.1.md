本次版本以小说翻译与下载交互的打磨为主：降低翻译任务被模型内容过滤误拒的概率、模型列表可缓存复用，统一全局细滚动条，并修正下载按钮文案的显示规则。

## 新增

- **模型列表缓存**：设置页「获取模型」成功后，模型列表随设置保存；下次打开设置或小说翻译浮窗时无需重新获取即可下拉选择，切换 API 地址或接口协议时自动清空。
- **复制模型 ID**：小说翻译浮窗的模型选择框旁新增复制按钮，一键复制当前模型 ID。

## 优化

- **降低内容过滤误拒**：翻译 / 审查子 Agent 的系统提示词只保留通用基础提示，角色与工具约定改随首条用户消息注入，冻结术语与风格改随分块读取结果返回。system 位置是内容过滤权重最高的位置，不再承载可变的角色与约束内容后，派发翻译请求被服务商内容过滤误拒（`content_filtered`）的概率明显降低；术语与风格约束的内容不变，仍随分块一并提供给模型。
- **模型下拉更易读**：翻译浮窗的模型选择框未展开时单行省略截断、不再撑破布局，展开后超长模型 ID 在菜单内换行完整显示，菜单限制最大宽度。
- **全局细滚动条**：全应用滚动条统一为 6px 细滚动条（透明轨道、圆角细滑块、隐藏上下箭头），此前仅查看器、阅读器等局部区域生效，其余区域使用系统默认宽滚动条。
- **翻译浮窗高度稳定**：小说翻译浮窗改为固定高度（内容多时内部滚动），页签切换与内容变化时不再跳动。

## 修复

- **下载按钮文案**：单件来源（小说单篇、插画单页与动图）主按钮统一显示「下载」，不再误显示「下载全部」；多件集合（系列 / 用户全集等）才区分「下载全部」与页选择器中的「下载所选 N 项」。
