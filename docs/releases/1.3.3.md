本次版本以浏览体验与可靠打磨为主：下载历史新增宫格模式并回显本地已下载图片，搜索新增收藏数档位过滤并修复分页错乱，「推荐」与「为你发现」合并为统一推荐页，设置保存失败可精确定位到出错字段；另包含一批可访问性、竞态与性能修复。

## 新增

- **下载历史宫格模式**：下载历史支持「列表 / 宫格」双模式切换，宫格模式直接回显本地已下载图片的首图（不再依赖网络缩略图），小说条目呈现专属立体书本封面并摘录前几行试读；显示偏好自动记忆。任务卡片同步改为两行紧凑布局，进度与删除动作对齐更清晰。
- **搜索收藏数档位过滤**：搜索页新增收藏数档位选择（100 / 500 / 1000 / 5000 / 10000 收藏以上），可快速筛掉低热度结果；该过滤借 pixiv 社区评价标签实现，为下限过滤而非排序，不改变现有排序方式。
- **统一推荐页**：原「推荐」与「为你发现」合并为单一推荐页，改为流式连续加载，浏览不因翻页打断。
- **设置保存错误可定位**：设置保存失败时明确提示出错的字段并自动滚动聚焦到该项，不再是笼统的整表报错。

## 修复

- **小说搜索分页错乱**：pixiv 搜索接口的每页条数按端点区分（插画 / 漫画 60 条、小说 30 条），此前统一按 60 条换算导致小说搜索的显示页出现「20 / 10 / 0」循环。现分页按端点对齐：插画 / 漫画维持 20 条一显示页，小说一接口页即一显示页（30 条）。
- **浏览健壮性**：修复追更列表、作者页与评论回复的加载竞态（快速操作不再串页），详情页加载失败补重试按钮，搜索刷新后保留当前页码；查看器支持键盘重试并修复焦点圈闭，单页作品不再误触发滚轮翻页拦截。
- **弹层与焦点**：各弹层关闭后焦点正确返回触发控件，阅读器内的弹窗不再被翻页快捷键误关。
- **任务与设置防重入**：任务清理与设置保存增加防重入，连点不会产生重复请求；数字输入框对非法输入的容错更稳。
- **翻译任务守卫**：修复翻译等待上限校验与预览写入的 token 越界问题。

## 优化

- **可访问性**：确认弹窗、账号菜单、导航等补齐可访问名称与键盘导航，登录错误就地显示，列表加载状态对读屏播报。
- **性能**：日志轮询与翻译预览重取增加节流，滚动回调合帧，长列表滚动更顺滑。
- **视觉规范回归**：翻译浮窗与状态色、浮层底色统一接入设计 token，深浅主题表现一致。
