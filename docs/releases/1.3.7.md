本次版本围绕阅读与安装体验：系列小说的跨话导航移入阅读器底栏并补齐「上一话」，浏览各处作品网格统一改为列数档位、整页每行铺满；Windows 安装器桌面快捷方式改为可选、默认不创建。

## 新增

- **系列小说跨话导航**：小说阅读器底栏翻页组两端新增「上一话 / 下一话」图标按钮（双 chevron 造型，与页内翻页的单 chevron 区分）——上一话按系列顺序自动解析（容忍系列跳号）、下一话直达官方下一话 ID；已是首话 / 末话或解析失败时按钮自动禁用，不打断当前阅读。原正文后的「下一话」按钮随之下线，入口统一收拢到底栏。

## 优化

- **作品网格列数档位铺满**：搜索、系列目录、排行、频道、浏览历史、下载历史等页码分页的作品网格统一挂共享列数档位——列数只取每页条数的因数，任意窗口宽度下整页每行都排满、末行不再残缺；纯 CSS 容器查询实现，窄窗自动收列、宽屏自动升档，无容器环境回退原有自适应布局。

## 变更

- **Windows 安装器桌面快捷方式改为可选**：MSI 安装向导的目录选择页新增「Create desktop shortcut」复选框，默认不勾选、不再默认创建桌面快捷方式（开始菜单快捷方式不受影响）；勾选状态会记住，应用内更新安装时沿用上次的选择。
