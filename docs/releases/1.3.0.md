本次版本把小说翻译从「单页两轮」升级为「整篇作品一个任务」：由新的 Agent 运行层统一调度翻译、审查与返工，支持后台并行、暂停 / 继续 / 取消、术语确认、分块预览与问题列表；设置页同步拆成一级常用项与二级高级项。

## 新增

- **整篇作品翻译**：一次启动处理一篇小说的全部阅读页，先通读全文整理术语、人物关系与文风，再分块翻译、独立审查、局部返工和整体复核，最后统一发布。系列中的其他作品仍各自独立翻译，不共享术语。
- **后台并行**：不同小说可以同时翻译，同一本小说保持串行；底部状态栏显示在途任务，多个任务时点开可切换到对应小说。关闭翻译浮层或离开阅读页都不会取消任务。
- **暂停 / 继续 / 取消**：暂停会停在最近的检查点，继续从断点接着做，已完成且有效的块不会重复请求；取消立即停止并保留已提交的译文与检查点。
- **翻译前确认术语**：可在设置中开启「翻译前确认术语与风格」。开启后任务先整理共享术语与文风并等待确认，浮层内可直接修改译名、译注和风格说明，再继续翻译正文。
- **预览与问题**：翻译浮层新增「预览」页签，按块查看原文与译文对照（未译块明确标示）；「问题」页签汇总审查发现，未解决块与严重问题优先展示。
- **设置分层**：设置页「小说翻译」一级只保留接口协议、API URL、API Key、模型、目标语言、确认开关与连接检测；并发、预算、重试、分块、压缩与诊断收进二级「高级设置」，按分类进入，支持恢复本组或全部推荐值，保存失败会自动定位到出错字段。
- **翻译进度事件**：任务状态改由后端任务统一推送，断线或重新进入页面后按快照补齐进度，不再依赖单次翻译请求的进度通道。

## 重要提示

- **模型调用次数会明显增加**：整篇翻译包含全文术语扫描、分块翻译、独立审查、整体复核和可能的返工，调用量高于原来的单页两轮。应用提供累计调用预算、并发上限、暂停 / 取消来控制成本，但不承诺固定费用；建议先用短篇确认服务与参数。
- **清空翻译缓存会同时删除恢复数据**：维护页清理「翻译」缓存时，会删除旧译文、分块、术语、审查记录、检查点、会话与临时文件，而不只是最终译文；暂停、等待确认或已中断的任务在清理后不可恢复。
- **旧译文只读兼容**：1.2.x 及更早版本产生的单页译文仍可在阅读器中读取，但会标记为部分完成，不会自动升级为已审查的整篇结果；重新翻译会创建新任务。
- **旧单页翻译命令已移除**：应用内部已不再注册单页翻译入口，阅读器统一发起整篇任务；升级不会影响已下载的小说、图片、登录态或设置。
- **安装方式不变**：本次同时把构建基线升级到 Rust 1.99.1，并接入 Rig 0.45 作为 Agent 协议与工具循环层；HTTP、代理、凭据与 pixiv 指纹伪装保持原实现。安装包、数据目录与既有登录态无需迁移。

## 说明

- 本次未声称已用真实付费模型完成长篇参数校准。并发、分块、预算与压缩的默认值是推荐起点，实际效果会随服务、模型、上下文窗口与作品长度变化；可在二级「高级设置」中调整并观察日志中的阶段摘要。
- 翻译运行参数、任务状态与缓存布局的完整说明见 `docs/SPEC.md` §4.3 / §5.2 / §7.1；架构决策见 ADR 0034、0035、0036。
- **上下文窗口默认调大**：模型上下文窗口的推荐值从 32768 提升到 131072（适配当前 128K 及以上窗口的模型），1.2.x 存量配置中的旧默认会在升级后自动迁移；手动改过该值的用户不受影响。
- **运行层防护与续跑**：模型一轮并行读取过多分块时，运行层按单轮结果预算自动分批（模型收到跳过提示），不再因一次批量读取超出上下文窗口而失败；旧轮次结果由压缩摘要，极端情况下紧急截断兜底。模型中途输出说明文字不再使任务停在原地，任务会依据检查点自动续跑直到完成或连续无进展。
- **续跑指令**：自动续跑时由运行层直接给出下一步动作、待办块清单与「必须调用工具」的要求，不再让模型凭状态汇报猜测进度；扫描结果误写在普通回复里的情况会被纠正并要求通过工具提交。
- **限流自动重试**：模型服务返回 429 或暂时性错误时，任务按「高级设置」里的重试次数与退避自动重跑，不再一次失败就要求人工处理；暂停 / 取消会立即中断退避等待。
- **模型拒绝的说明**：模型因内容策略拒绝处理（例如作品含未成年角色的露骨描写）而未调用任何工具时，任务以「模型拒绝或未调用工具即结束」停止，并直接展示模型给出的原因，不再反复重试消耗额度。
- **底栏文案**：翻译任务尚未定位到具体页面时省略页码，不再显示「页码未知」占位。
- **调用预算上调**：自动公式从 `32 + 16 × 分块数` 提高到 `64 + 32 × 分块数`（4 块作品由 96 次提升到 192 次），仍可在「高级设置 → 整篇累计调用预算」自定义；0 表示自动。
- **失败不再拖停整批**：单个分块结果未知时只标记该块，其余分块照常派发；该块在用户手动恢复前不会重复请求。
- **预览与计数一致**：预览页的块列表改按分块计划显示，细分后的任务不会出现已废弃块或漏块；翻译 / 审查进度变化时自动刷新预览状态。
- **审查不再因输出截断失败**：审查子任务降低思考强度并要求直接提交结论、限制问题条目长度，避免模型先写长篇分析而把结构化输出挤出网关的输出上限。
- **审查只拦严重问题**：润色、轻微格式等 `minor` 建议仍会列出，但不再把分块判为不通过，也不再阻塞整体复核与交付；漏翻、错译、术语错误等 `major` / `critical` 问题仍会阻止完成。
- **严重问题优先定点修订**：审查指出个别片段的问题时，协调者直接替换对应片段并重新审查，不再整块丢弃重译，避免重译引入新的问题。
- **返工次数按分块独立计算**：每个分块各有自己的返工额度，一块反复不收敛不会耗尽其他块的修复机会；失败时按块报告，其他块照常完成。点「继续」会清空已用返工次数，重新给予修复机会。
- **进度计数与错误提示修正**：收尾计数改为从磁盘产物重算，不再出现计数被覆盖成 0；审查未完成与返工额度用尽分别提示，不再误报为整体复核失败。
