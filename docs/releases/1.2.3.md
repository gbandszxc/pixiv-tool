本次版本以翻译体验为主：翻译进度实时可见并支持后台续跑，浮窗流式显示模型思考过程与 token 用量，多本小说可同时后台翻译，输出上限按输入分档并默认开启思考；下载支持自定义文件名模板；界面新增日语。

## 新增

- 翻译实时进度：小说页发起翻译后实时显示当前阶段（排队 / 整理设定集 / 翻译正文）与已接收字节数、流式摘要；离开页面翻译继续在后台进行，底部状态栏显示「翻译中」并可点击跳回小说页；翻译失败在回到页面时展示原因并可直接重试。
- 翻译浮窗流式展示：翻译期间浮窗实时滚动显示模型的思考过程与流式摘要，译文正文到达后即时接替展示；完成后显示两轮请求的 token 用量（输入 / 输出）。
- 多小说并行翻译：翻译串行锁从全局降为按小说，多本小说可同时后台翻译、互不排队；底部状态栏聚合进行中的翻译任务，多个任务时点击浮出菜单，可选择跳转到对应小说页。
- 下载文件名模板：设置弹窗新增「下载」分组，插画与小说（单篇 / 系列）支持自定义文件名模板，可用 `{title}` `{user}` `{uid}` `{pid}` `{page}` `{nid}` `{order}` `{sid}` 等占位符；默认模板保持现有命名不变，非法模板保存时会被拒绝并标红提示。
- 界面日语：新增完整的日语界面，用语贴近 pixiv 用户习惯，可在设置中切换。

## 优化

- 翻译进度区移入浮窗，流式摘要超长时横向走马灯滚动；浮窗加宽，完成后自动刷新内容，跳回小说页时自动展开。
- 设置弹窗分组重组：下载相关设置独立成组，取消「高级」分组。
- 翻译输出上限按本次输入长度自动分档（16k / 64k / 256k），并默认开启模型思考，长页与深度思考不易再被截断；因输出上限截断时会单独提示并附实际生效的上限值。

## 修复

- 翻译：思考参数按接口协议归一化下发，修复 Anthropic 与 Responses 协议下思考不生效的问题。
