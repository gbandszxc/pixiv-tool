本次版本围绕竖屏与大屏使用体验、以图识图与搜索效率：新增竖屏最大化专用布局（侧栏自动折叠、详情页上下堆叠、翻译浮窗贴底抽屉等），以图识图与浏览关键词搜索均新增搜索历史并可一键回填，SauceNAO API Key 纳入 WebDAV 加密同步；浏览正文中的 pixiv 链接改为应用内直达。

## 新增

- **正文内链应用内直达**：评论区、小说正文（`[[jumpuri:文字 > URL]]` 锚文本与裸 URL，原文与译文同规则）、作品 / 小说描述、系列简介、作者简介中的 pixiv 链接，凡对应应用内已封装页面（作品 / 小说 / 用户 / 系列）均点击站内跳转、返回键逐层回退；其余链接（pixiv 标签页、jump.php 解码后的外部目标、其他网站）仍走系统默认浏览器。识别与渲染全程纯文本分段，不执行任何 HTML。

- **竖屏最大化专用布局**：窗口最大化且逻辑宽高比 < 0.8、高度 ≥ 900 时自动启用——侧栏折叠为 72px 图标栏（手动折叠 / 展开可覆盖自动决策且不持久化）、作品详情页改为上下堆叠、小说阅读器正文限宽居中、整篇翻译浮窗改为贴底抽屉、底部任务选择器贴底停靠不越界、下载面板收窄；非最大化窗口沿用横屏布局，不按设备物理方向硬判定（ADR 0052）。
- **以图识图搜索历史**：每次成功反搜自动记录（缩略图 + 来源标签 + 命中数 + 相对时间，最新在前，保留最近 200 条）；点击历史条目即采纳该源并立即搜索，hover 单条删除，设置维护分区可一键清空全部；页面站内打开→返回不再丢失输入与结果。
- **浏览搜索历史**：插画 / 漫画 / 小说关键词搜索第一页成功后自动记录（关键词 + 过滤条件六元组去重，保留最近 200 条）；搜索框聚焦 / 输入时弹出历史下拉，条目含关键词 + 类型徽标 + 相对时间，点击直接回填查询参数并搜索，支持 ↑↓ 键盘选择与单条删除，设置维护分区可一键清空全部。
- **SauceNAO API Key 纳入 WebDAV 同步**：同步范围新增「以图识图 Key」，随加密同步包传输；上传 / 恢复回执只提示是否携带或已恢复，不回显 Key 原文（ADR 0053）。

## 优化

- **以图识图输入区重构**：整卡拖拽热区（任意模式下拖图即可用）、「使用图片 URL」次级入口可切换、大图预览与搜索主按钮上下相邻；本地预览改走应用内下载协议，修复部分本地图片显示裂图；API Key 未配置时的引导条提供「获取 API Key」外链与一键直达设置对应分区并聚焦该字段。

## 修复

- 浏览搜索历史下拉提层不再被筛选栏压回穿透；以图识图历史区超长时限高内部滚动。
- 设置页「删除 Key」字段不再出现双层聚焦高亮。
