### Ticket V2-01: src layout 重构（F2.3 + F2.4 合并，强联动）

**为什么合并**：F2.3（pyproject 位置）和 F2.4（tests 位置）在 src layout 迁移里是同一次机械改动，拆开反而要改两次 import。

**方案**：
```
当前:                          目标:
backend/                       src/
├── api/                       └── pixiv_tool/
├── auth/                            ├── api/        (子包名不动,无冲突)
├── core/                            ├── auth/
├── storage/                         ├── core/
├── main.py                          ├── storage/
└── static/                          ├── main.py
                                     └── static/
tests/                         tests/                (保留 root,只改 import)
pyproject.toml (root)          pyproject.toml (root,packages 指向 src/pixiv_tool)
```

**tests 位置决策**：保留 root `tests/`。理由：src layout 下 root tests/ 是主流（pytest 默认发现 + conftest sys.path 最简）；F2.4 原描述"移到 backend/tests/"是基于旧布局，src layout 后 SPEC §3.4 要同步更新这个约定。

**66 处 import 机械改写规则**：
- `from backend.` → `from pixiv_tool.`
- `import backend` → `import pixiv_tool`
- `backend.main:app` → `pixiv_tool.main:app`（dev.ps1、uvicorn CLI）

**7 处连锁改动点**（ticket 17 记录的）：
| 文件 | 改什么 |
|---|---|
| `pyproject.toml` | `[tool.hatch.build.targets.wheel] packages = ["backend"]` → `["src/pixiv_tool"]` |
| `pixiv-tool.spec` | 入口 `backend/main.py`→`src/pixiv_tool/main.py`；`backend/static`→`src/pixiv_tool/static`；hiddenimports `backend.auth.login_window`→`pixiv_tool.auth.login_window`(2 处)；datas 目标；docstring |
| `scripts/dev.ps1` | line 280/282 `backend.main:app` → `pixiv_tool.main:app` |
| `scripts/build.py` | line 29 `BACKEND_DIR = REPO_ROOT / "backend"` → `"src" / "pixiv_tool"`；line 30 static 目标 |
| `tests/conftest.py` | line 13 sys.path.insert + 所有 fixture 里的 `from backend.` |
| `.venv` | `uv sync` 重建 editable install（自动） |
| `docs/SPEC.md §3.4` + `docs/PACKAGING.md` | 目录结构图同步更新 |

**验收标准**：
- [ ] 90 个测试全过（import 改对 + 功能没坏）
- [ ] `./scripts/dev.ps1 start` → http://localhost:9961/ 前端渲染 + 后端 health 200

### Ticket V2-02: 前端 + 依赖技术债

**3 个子项**：

1. **`frontend/pnpm-lock.yaml` 入库**（SESSION §2.2 记录）
   - 现状：untracked，团队拉代码后 pnpm install 可能装到不一致版本
   - 修法：`git add frontend/pnpm-lock.yaml` + 单独 `chore(frontend): 跟踪 pnpm-lock.yaml` commit
   - 验证：clone 到新目录 + pnpm install --frozen-lockfile 不报错

2. **`auth.ts` 动态+静态导入冲突**（Vite code-split warning）
   - 现状：`api/index.ts` 动态 import `stores/auth`，但 `App.vue` + `SettingsView.vue` 静态 import → Vite 警告 "dynamically imported but also statically imported, dynamic import will not move module into another chunk"
   - 修法：统一成静态 import（auth store 本来就该在主 bundle，没必要 code-split）
   - 验证：`pnpm build` 无该警告

3. **`httpx2` 弃用警告跟踪**
   - 现状：FastAPI test client 依赖 httpx，starlette 新版提示要用 httpx2
   - 修法：先登记观察，等 fastapi/starlette 主版本升级自然消化；不主动换 httpx2（API 不完全兼容，风险大）
   - 验证：CI 里 grep 该警告，记录出现版本，未来升级时检查

**验收**：3 个子项都有对应 commit + pnpm build 干净

**依赖**：无（独立，但建议在 V2-01 之后做，避免重构期两摊改动混在一起）

### Ticket V2-03: frozen 模式数据目录锚定修正

**问题**：db.py / cookie_dpapi.py / logging_config.py 都用 `Path(__file__).resolve().parent.parent.parent` 锚定数据目录。frozen 模式下 `__file__` 指向 `_internal/backend/storage/db.py`，三级 parent 是 `_internal/`，导致：
- 用户数据写到 `dist/pixiv-tool/_internal/data/app.db`（跟着 exe 走，升级覆盖丢失）
- `dist/pixiv-tool/_internal/config/cookies.dat`（DPAPI 加密的登录态，重打包会丢）
- 我在 PACKAGING.md §5 写的"数据存放在用户目录"是错的，实际是 `_internal/`

**当前不一致**：`main.py:_redirect_stdio_if_needed` 已经用 `sys.executable.parent/data/logs/`（exe 同级，升级安全），但 db/cookie 还用 `_internal/data/`——两套锚定逻辑冲突。

**方案（产品决策点，ticket 里列为 open question）**：
- 选项 A（portable 模式）：所有数据锚定 `<exe_dir>/data/` + `<exe_dir>/config/`，和 stdout.log 一致。优点：解压即用、数据跟着 exe、便携。缺点：升级要用户手动迁移数据。
- 选项 B（installed 模式）：用 `platformdirs.user_data_dir("pixiv-tool")` → `%APPDATA%/pixiv-tool/`。优点：升级不丢数据、符合 Windows 应用规范。缺点：便携版用户找不到数据。
- 选项 C：A + 给 settings 加个"数据目录"配置项，默认 portable，可改 installed。

**统一改动的文件**：
- `backend/storage/db.py` line 17 `DB_DIR`
- `backend/storage/cookie_dpapi.py` line 18 `COOKIE_FILE`
- `backend/logging_config.py` line 13 `_LOG_DIR`
- 抽一个 `backend/storage/paths.py` 统一锚定逻辑（DRY）

**验收标准**：
- [ ] frozen exe 双击 → 数据写到统一位置（不管选 A/B/C）
- [ ] 重打包（删 dist 重建）→ 用户数据不丢
- [ ] PACKAGING.md §5 数据存放表更正
- [ ] 3 个文件不再各自算 `__file__.parent.parent.parent`

**依赖**：无（但 V2-01 的 src layout 改完后 paths.py 放 `src/pixiv_tool/storage/paths.py`）
